# تشغيل دوكو على GitHub Pages — 0.5.1

الرابط: https://iambelmo.github.io/DUKO/

تفتح اللعبة نفسها على هذا الرابط، وتبقى صفحة اللعب على GitHub Pages. الواجهة تستخدم نفس خادم الغرف وقاعدة البيانات الموجودين على https://duko-club-belmo.max083522.chatgpt.site؛ يستطيع اللاعبون على الرابطين الانضمام إلى الغرفة نفسها.

## إعداد GitHub

في Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)`.

ملف `index.html` يشغّل الواجهة، وملف `.nojekyll` يطلب نشر الملفات الثابتة مباشرة. لا توجد إعادة توجيه أو صفحة README بديلة. رابط دعوة الغرفة يحافظ على مسار المستودع `/DUKO/`.

يمكن تغيير اسم الجزء الأخير من الرابط بتغيير اسم المستودع. الملفات ومسارات الدعوات نسبية، ولذلك لا تحتاج إعادة كتابة مسارات الأصول عند تغيير اسم المستودع داخل الحساب نفسه. تغيير حساب GitHub أو استخدام دومين مختلف يتطلب تحديث أصل الواجهة المسموح به على الخادم.

## ما تغير

- توليد مدخل Pages من نفس قالب HTML الذي تستخدمه النسخة المستضافة: `node scripts/build-pages.mjs`.
- رابط الخادم معرف داخل مدخل Pages فقط. النسخة المستضافة تستمر باستخدام طلبات إلى نفس أصل الصفحة.
- الخادم يقبل طلبات Pages من `https://iambelmo.github.io` تحديدًا، ويتحقق من الجلسة وصلاحيات اللاعب في كل طلب.
- جلسة Pages تستخدم رمزًا عشوائيًا محفوظًا في ذاكرة التبويب `sessionStorage`؛ الخادم يحتفظ بتجزئته فقط. لا يعتمد اللعب على السماح بملفات ارتباط الطرف الثالث.
- تحديث الصفحة يعيد جلسة التبويب. إغلاق التبويب ينهي حفظ الرمز فيه؛ الدخول في تبويب جديد ينشئ جلسة جديدة عادةً. إن منع المتصفح التخزين، تظل الجلسة في الذاكرة حتى تحديث الصفحة.
- رمز الجلسة لا يدخل رابط الدعوة، ولا حالة الواجهة المعروضة، ولا ملفات GitHub. واجهة Pages لا تستخدم ملفات ارتباط النسخة المستضافة لتسجيل الدخول.
- تطبيق الويب وملفات التخزين المؤقت محصورة بمسار اللعبة؛ لا تُخزّن طلبات الغرف أو بيانات الأوراق في Service Worker.
- لم تتغير قواعد اللعب أو السكور أو آلية الحرق.

## التحديث والتحقق

```sh
node scripts/build-pages.mjs
node --test test/*.test.ts test/*.test.mjs
```

انشر تغييرات الخادم على استضافته أولًا، ثم حدّث ملفات GitHub. تغيير ملفات الخادم في GitHub وحده لا ينشرها على خادم الغرف.

تشمل الاختبارات اتصال واجهة Pages بالخادم، انضمام لاعب من الرابط الآخر، خصوصية الأوراق، تحديث الصفحة، الجلسة القديمة، روابط الدعوة، وسياسة طلبات CORS. يلزم اختبار بصري ولمس فعلي على الأجهزة للتحقق من تجربة الاستخدام الكاملة.
