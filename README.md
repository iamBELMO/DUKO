# دوكو — DUKO CLUB

لعبة ورق عربية أونلاين من 2 إلى 6 لاعبين، بغرف خاصة، حرق سريع، كرامات 7–10، ولاعبين آليين.

**[افتح اللعبة](https://duko-club-belmo.max083522.chatgpt.site)**

هذا مستودع مصدر النسخة المنشورة. اللعبة تعمل على الاستضافة حتى عندما يكون جهاز صاحبها مغلقًا.

## آخر تحديث — 0.5

- الحرق متاح للجميع، حتى صاحب الرمية، خارج ترتيب الأدوار. كل حرق صحيح يفتح نافذة جديدة؛ السيرفر يحسم أسرع عملية صحيحة.
- اضغط النار لتمسك ورقتها، ثم اسحبها فوق الورقة التي تريد استبدالها أو أرجعها إلى النار. ورقة مأخوذة من النار لا تفعّل كرامتها عند إرجاعها.
- تستطيع الحرق خلف رميتك مباشرة إذا عندك نفس الرتبة. الطلب المتأخر لا يفرض عقوبة، والحرق الخاطئ يضيف ورقة مقلوبة.
- إعلان نهاية الجولة اسمه «دوكو». الحساب ينتظر انتهاء آخر سلسلة حرق.
- تصميم أزرق ملكي وطاولة كحلية، ورق مرسوم برموز SVG، وحركة توزيع وسحب وحرق وكشف نتائج، وصوت اختياري.
- رابط [BELMO على تيليجرام](https://t.me/iamBELMO) أول عنصر أعلى الصفحة.
- لا توجد اعتماديات جديدة. تفاصيل كل الملفات المعدّلة في [دليل تحديث 0.5](docs/UPDATE-0.5-AR.md).

## الاستضافة والرابط

- الواجهة وخادم الغرف يعملان على Cloudflare Workers مع قاعدة D1، عبر Sites.
- GitHub يحفظ الكود؛ رفعه هنا أو تغيير اسم المستودع لا يغيّر رابط اللعبة تلقائيًا.
- GitHub Pages يستضيف ملفات ثابتة، ولا يشغّل خادم هذه اللعبة أو قاعدة الغرف.
- للحصول على اسم مستقل، اربط نطاقًا تملكه بالاستضافة الحالية، ثم أضف سجلات DNS التي تعرضها الاستضافة. لا حاجة لنقل اللعبة إلى Pages.
- هذه نسخة من المصدر عند الرفع. لم يُفعّل نشر تلقائي من GitHub إلى الاستضافة.

## محتويات المشروع

| المجلد | الوظيفة |
| --- | --- |
| `src/` | قوانين اللعب، النقاط، ترتيب الأدوار، وإخفاء الأوراق |
| `lib/hosted.ts` | الجلسات والغرف وحفظ الحالة ومعالجة الأوامر |

## الفحص

تحتاج Node.js 24. يمكن تشغيل اختبارات المنطق والخادم دون إعداد قاعدة بيانات إنتاج:

```sh
node --test test/*.test.ts test/*.test.mjs
```
