# دوكو — DUKO CLUB

لعبة ورق عربية أونلاين من 2 إلى 6 لاعبين، بغرف خاصة، حرق سريع، كرامات 7–10، ولاعبين آليين.

**[العب دوكو على GitHub Pages](https://iambelmo.github.io/DUKO/)** · [رابط الاستضافة الآخر](https://duko-club-belmo.max083522.chatgpt.site)

هذا مستودع مصدر النسخة المنشورة. اللعبة تعمل على الاستضافة حتى عندما يكون جهاز صاحبها مغلقًا.

## آخر تحديث — 0.5.1

- رابط GitHub Pages يفتح واجهة اللعبة مباشرة، مع غرف مشتركة مع الرابط الآخر.
- يدعم تحديث الصفحة وروابط دعوة الغرف تحت `/DUKO/`، ولا يعتمد على ملفات ارتباط الطرف الثالث.
- إعداد النشر: **Settings → Pages → Deploy from a branch → main → /(root)**.
- التفاصيل التقنية وطريقة تغيير اسم الرابط في [دليل GitHub Pages](docs/GITHUB-PAGES-AR.md).

- الحرق متاح للجميع، حتى صاحب الرمية، خارج ترتيب الأدوار. كل حرق صحيح يفتح نافذة جديدة؛ السيرفر يحسم أسرع عملية صحيحة.
- اضغط النار لتمسك ورقتها، ثم اسحبها فوق الورقة التي تريد استبدالها أو أرجعها إلى النار. ورقة مأخوذة من النار لا تفعّل كرامتها عند إرجاعها.
- تستطيع الحرق خلف رميتك مباشرة إذا عندك نفس الرتبة. الطلب المتأخر لا يفرض عقوبة، والحرق الخاطئ يضيف ورقة مقلوبة.
- إعلان نهاية الجولة اسمه «دوكو». الحساب ينتظر انتهاء آخر سلسلة حرق.
- تصميم أزرق ملكي وطاولة كحلية، ورق مرسوم برموز SVG، وحركة توزيع وسحب وحرق وكشف نتائج، وصوت اختياري.
- رابط [BELMO على تيليجرام](https://t.me/iamBELMO) أول عنصر أعلى الصفحة.
- لا توجد اعتماديات جديدة. تفاصيل كل الملفات المعدّلة في [دليل تحديث 0.5](docs/UPDATE-0.5-AR.md).

## الاستضافة والرابط

- واجهة اللعب تعمل على GitHub Pages، وخادم الغرف يعمل على Cloudflare Workers مع قاعدة D1، عبر Sites. النسخة المستضافة الكاملة متاحة أيضًا.
- تغيير اسم المستودع يغيّر مسار رابط Pages بعد إعادة النشر. المسارات الداخلية للواجهة نسبية وتحتفظ باسم المستودع في دعوات الغرف.
- GitHub Pages يشغّل الواجهة؛ خادم الغرف وقوانين اللعب والنقاط تبقى على السيرفر.
- للحصول على اسم مستقل، اربط نطاقًا تملكه بالاستضافة الحالية، ثم أضف سجلات DNS التي تعرضها الاستضافة. لا حاجة لنقل اللعبة إلى Pages.
- تحديث ملفات الواجهة في `main` ينشرها عبر Pages. تعديل ملفات الخادم في GitHub لا ينشرها تلقائيًا على استضافة السيرفر.

## محتويات المشروع

| المجلد | الوظيفة |
| --- | --- |
| `src/` | قوانين اللعب، النقاط، ترتيب الأدوار، وإخفاء الأوراق |
| `lib/hosted.ts` | الجلسات والغرف وحفظ الحالة ومعالجة الأوامر |
| `app/` و `public/` | الواجهة العربية المتجاوبة وملفات تطبيق الويب |
| `db/` و `drizzle/` | قاعدة البيانات وترحيلاتها |
| `test/` | اختبارات القواعد والخصوصية والتزامن |

## الفحص

تحتاج Node.js 24. يمكن تشغيل اختبارات المنطق والخادم دون إعداد قاعدة بيانات إنتاج:

```sh
node --test test/*.test.ts test/*.test.mjs
```

عند تعديل قالب HTML أو إعدادات النسخة الثابتة، أعد توليد مدخل Pages قبل الرفع:

```sh
node scripts/build-pages.mjs
```

نجحت 57 حالة اختبار على مصدر هذه النسخة، بالإضافة إلى فحص TypeScript والبناء. تشمل الاختبارات الاتصال بين واجهة Pages وخادم الغرف، خصوصية الأوراق، وصلاحيات الجلسات. لم يُجرَ فحص بصري بالمتصفح أو تجربة لمس فعلية على الهاتف. لا يعني ذلك ضمان خلو اللعبة من جميع الأخطاء.

تفاصيل التشغيل والبناء والقيود موجودة في [دليل النسخة المستضافة](docs/HOSTED-EDITION.md). يتضمن المصدر تعريف الموقع الحالي؛ إنشاء استضافة مستقلة يحتاج إعداد مشروع وقاعدة بيانات تخصها. لا يتضمن هذا المستودع جلسات اللاعبين أو أوراق الغرف أو مفاتيح الوصول.
