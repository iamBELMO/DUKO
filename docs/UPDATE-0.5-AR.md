# تحديث دوكو 0.5

التصميم يعتمد الأزرق الملكي وهوية DUKO، مع طاولة كحلية عميقة.
البرتقالي مخصّص للنار ولحظات الحرق، والذهبي لنتيجة الفوز.
الورق صار بفهارس واضحة ورموز SVG بدل الاعتماد على شكل رموز الخط.
حركة الورقة توضّح السحب والاستبدال والرمي، والظل يوضّح حالة الإمساك.
رابط تيليجرام أول عنصر أعلى الصفحة، والنص العربي واتجاه RTL محفوظان.

## كيف تلعب بالتحديث

1. في دورك اضغط الرزمة أو النار لتمسك ورقة. ورقة النار يظهر تحتها «من النار · بإيدك».
2. اسحب المسحوبة فوق الورقة التي تريد استبدالها. الضغط على ورقتك يبدّلها أيضًا.
3. أو اسحب المسحوبة للنار لترميها. رمي ورقة أخذتها من النار لا يفعّل كرامتها.
4. بعد أي رمية، الجميع يقدروا يحرقوا، حتى صاحب الرمية: اسحب ورقتك المطابقة للنار. بديل السحب: اختر ورقتك ثم اضغط النار. استخدم «حرق سريع» إذا كنت تختار كرامة بنفس الوقت.
5. أول حرق صحيح يحسمه السيرفر يزيل ورقة ويفتح نافذة جديدة للجميع. الحرق الخاطئ يضيف ورقة مقلوبة؛ الطلب المتأخر لا يضيف عقوبة. اللون والنوع لا يلزمان؛ المطابقة بالرتبة.
6. إعلان النهاية اسمه «دوكو». باقي اللاعبين يأخذون دورهم الأخير، والحساب ينتظر انتهاء الحرق الأخير.

الغرفة التي بدأت جولة قبل هذا التحديث تحتاج بدء جولة جديدة لتطبيق قواعد الحرق الجديدة. حدّث الصفحة على كل الأجهزة بعد النشر.

## الملفات الكاملة التي تغيّرت

الأرشيف الكامل يحتوي المشروع بكل ملفاته. كل ملف مما يلي كامل وجاهز للاستبدال في نفس المسار، وليس مقتطفًا أو patch. يجب تطبيق الملفات معًا حتى تتطابق واجهة اللعب مع محركها.

| الملف | التغيير |
| --- | --- |
| `public/app.js` | إمساك النار، سحب واستبدال، حرق صاحب الرمية، تيليجرام أول الصفحة، إعلان دوكو، واجهة ونتائج وإتاحة لوحة المفاتيح |
| `public/styles.css` | نظام التصميم الكامل، الورق، الطاولة، التجاوب، حالات الاختيار وتقليل الحركة |
| `public/card-art.js` — جديد | رسومات الورق والرموز والفهارس والجوكر |
| `public/effects.js` — جديد | حركة التوزيع والسحب والرمي والكشف والنتائج ومؤثرات النار |
| `public/sounds.js` — جديد | أحداث صوت خفيفة واهتزاز اختياري |
| `public/sw.js` | تحديث كاش ملفات التطبيق إلى 0.5.0 |
| `src/models.ts` | مصدر الورقة الممسوكة وبيانات سلسلة الحرق |
| `src/engine.ts` | قواعد الحرق للجميع وتسلسله، وإمساك النار قبل القرار |
| `src/privacy.ts` | إرسال مصدر الورقة لصاحبها فقط وبيانات نافذة الحرق العامة |
| `lib/schema.mjs` | التحقق من أمر إمساك النار الجديد |
| `lib/hosted.ts` | رقم إصدار فحص الخدمة فقط؛ آلية الشبكة والتخزين لم تتغيّر |
| `test/game.test.ts` | اختبارات القواعد والتوقيت والخصوصية والحرق المتتابع |

## الاعتماديات

لا توجد اعتماديات جديدة. المؤثرات تستخدم Web Animations وCSS وrequestAnimationFrame؛ الصوت يستخدم Web Audio. لا يوجد CDN أو خط أو صورة خارجية مطلوبة. ملفات JavaScript الجديدة تُستورد تلقائيًا من `app.js`.

## الفحوص البرمجية

من مجلد المشروع، بعد تثبيت اعتمادياته الموجودة:

```bash
node --test test/*.test.ts test/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit --incremental false
```

يحتوي المشروع 48 اختبارًا. اختبارات الواجهة تشغّل إنشاء HTML ومسارات الأحداث مع محرك اللعبة؛ لا تحاكي عرض المتصفح أو لمس آيفون فعلي. البناء النهائي يستخدم مسار Sites الرسمي للمشروع المستضاف. هذا الأرشيف مصدر كامل، ولا يحتوي جلسات اللاعبين أو قاعدة البيانات أو رموز الدخول أو `node_modules`.

## قائمة التجربة على الأجهزة

- [ ] حدّث الرابط على تلفونين أو متصفحين مستقلين، وابدأ جولة جديدة.
- [ ] امسك ورقة من النار، واستبدلها بسحبها فوق كل مكان من أماكن أوراقك الأربعة.
- [ ] أرجع ورقة النار، ثم احرق ورقة بنفس رتبتها من عندك قبل انتهاء النافذة.
- [ ] جرّب الحرق من لاعبين معًا؛ واحد يفوز بالنافذة، وبعد تحديثها يستطيع الآخر الحرق خلفه. جرّب حرقين متتاليين من نفس اللاعب.
- [ ] جرّب الحرق الغلط، والحرق بعد انتهاء النافذة، والتراجع بسحب الورقة خارج الطاولة.
- [ ] أعلن دوكو وتأكد أن الحساب ينتظر نهاية الحرق وأن أقل مجموع يفوز؛ التعادل يظهر كفوز مشترك.
- [ ] افحص عرض 360px، والوضعين الطولي والعرضي، واللمس في Safari، وتشغيل الصوت وكتمه. الاهتزاز يتطلب دعم الجهاز والمتصفح.
- [ ] جرّب التنقل بـTab وEscape والاختصارات، وتفعيل تقليل الحركة من إعدادات الجهاز.
- [ ] اضغط تيليجرام أعلى الصفحة وتأكد أنه يفتح `https://t.me/iamBELMO`.

الأسرع في الحرق يُحسم من أول عملية صحيحة تُثبت في السيرفر؛ سرعة الاتصال تؤثر على السباق. نافذة كل حرق 1.5 ثانية كما كانت. لا يوجد وعد بأن أي برنامج خالٍ تمامًا من الأخطاء، ولا ادعاء بإجراء تجربة بصرية أو لمس فعلية في هذه البيئة.
